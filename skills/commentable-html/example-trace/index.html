bisect_left puts 8 at index 1, before both 8s already in the list, after 3 comparisons

Python 3.14.3's bisect.bisect_left, traced line by line on the sorted list [3, 8, 8, 15, 21, 40], a toy example picked for this page. trace.py beside this page ran the code and printed every value shown here.

In a nutshell

Setup: lo starts at 0 and hi at 6, so all 6 items are undecided

  • hi starts at 6, one past the last index, because 8 could belong after 40, at the end of the list.
  • So the insertion point can be any of 7 indexes, 0 to 6, and lo and hi bound all of them.
  • With key left as None, the code runs the first of its two loops, lines 94 to 99, which compares the items themselves.

Comparison 1: a[3] is 15, which is not below 8, so hi moves to 3

  • mid is (0 + 6) // 2 = 3, where // divides and rounds down. Of the two middle items, a[2] and a[3], that picks a[3].
  • The list is sorted, so 21 and 40 are at least 15, and one comparison settles all three items.
  • hi stops at 3 itself, because index 3 is still a possible insertion point. 8 goes there if a[0], a[1] and a[2] are all below 8.

Comparison 2: a[1] is 8, which is not below 8 either, so hi moves to 1

  • mid is (0 + 3) // 2 = 1, the middle of the 3 undecided items.
  • 8 < 8 is False, so an item equal to 8 goes with the items above 8. That is why bisect_left lands before every 8 already in the list.
  • bisect_right tests 8 < a[mid] instead. On this same item it moves lo to 2, and it returns 3, after both 8s.

Comparison 3: a[0] is 3, which is below 8, so lo moves to 1 and meets hi

  • mid is (0 + 1) // 2 = 0, because a[0] is the only undecided item.
  • lo = mid + 1 jumps past a[0], because 8 must go after every item below it.
  • Three comparisons settled six items. The undecided count went 6, 3, 1, 0, and each comparison left at most half.

Return: lo and hi both equal 1, so 8 goes in at index 1

  • The loop test 1 < 1 is False, so the loop stops after 3 passes and the function returns lo, which is 1.
  • Index 1 splits the list into a[:1] = [3], all below 8, and a[1:] = [8, 8, 15, 21, 40], all 8 or more.
  • The C version that a plain import bisect gives you also returns 1, so the traced Python code matches what you run.
